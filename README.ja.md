# ProjectFolderHider

[English](README.md)

Unity EditorのProjectウィンドウで、フォルダを非表示にしたり、再表示したりするためのツールです。

## コンセプト

ProjectFolderHiderは、UnityのProjectウィンドウ内の表示を整理し、操作性を向上させるために開発されました。

あまり使用しないツールやパッケージ、アセットなどを含むフォルダが多いと、大規模なプロジェクトでは目的のファイルを探しにくくなることがあります。

このツールでは、選択したフォルダを実際のファイルやデータを削除・変更することなく、Projectウィンドウ上で非表示にできます。

## 概要

- **Unityバージョン：** 2022.3.22f1
- **非表示・再表示メニュー：** `Assets > Toggle Folder in Project View`
- **管理ウィンドウ：** `nur_ieren > ProjectFolderHider`

## 機能

- **フォルダの非表示** — 選択したフォルダのProjectウィンドウ上での表示・非表示を切り替えます。
- **設定の永続化** — 非表示にしたフォルダのGUIDを `UserSettings/HiddenProjectFolders.txt` に保存します。
- **名前変更・移動への対応** — アセットのGUIDを使用してフォルダを識別するため、フォルダのパスが変更されても追跡できます。
- **個別フォルダの再表示** — 管理ウィンドウに非表示フォルダの一覧を表示し、個別に再表示できます。
- **すべてのフォルダの再表示** — `Show All` ボタンから、非表示にしたすべてのフォルダを一括で再表示できます。
- **ファイルの安全性** — 実際のアセットファイル、`.meta` ファイル、GUIDを削除・変更しません。

## 使い方

### フォルダを非表示にする

1. UnityのProjectウィンドウを開きます。
2. 非表示にしたいフォルダを1つ以上選択します。
3. 選択したフォルダを右クリックします。
4. `Toggle Folder in Project View` を選択します。

すでに非表示になっているフォルダを選択した場合は、再表示に切り替わります。

### 非表示にしたフォルダを再表示する

1. `nur_ieren > ProjectFolderHider` を開きます。
2. 再表示したいフォルダを一覧から探します。
3. 対象フォルダの横にある `Show` をクリックします。

非表示にしたすべてのフォルダを再表示する場合は、`Show All` をクリックします。

## 注意事項

- このツールが変更するのはProjectウィンドウ上のフォルダ階層の表示状態のみであり、プロジェクト内の実際のファイルやデータには影響しません。
- 非表示フォルダの設定は、ローカルの `UserSettings/HiddenProjectFolders.txt` に保存されます。
- 設定ファイルはアセットファイルとは別に管理されるため、必要に応じてバージョン管理の対象から除外できます。
- このツールはReflectionを通じてUnity Editorの内部APIを利用しています。UnityのProjectウィンドウの内部実装が変更された場合、互換性に影響する可能性があります。

## 開発について

このプロジェクトは、アセットを削除することなく、大規模なUnityプロジェクト内をより快適に移動・操作できるようにすることを目的として開発されました。
