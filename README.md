## Name
Projectタブにおいて指定したフォルダを非表示にすることから  
"ProjectFolderHider"  
としました。  

## Concept
ツールが入ってるフォルダなど、全く開かないのに幅を取るフォルダを非表示にするため作られました。

## Overview
Unity2022.3.22f1に導入してご利用下さい。  
無理やり動かしているため思い通りに動かないこともあるかもしれません。  

## Features
1カラムの際にフォルダを非表示にできます。
非表示解除も可能です。

## How to use
非表示にしたいフォルダを右クリック、下の方にある  
Toggle Folder in Project View  
を押して非表示にしてください。
非表示にしたフォルダはUnityメニュー > nur_ieren > ProjectFolderHiderから確認・解除できます。
